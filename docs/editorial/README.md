## Antes de publicar cada texto

- Um editor deve revisar, corrigir e aprovar a versão final, conferindo as fontes.
- Definir quem assume a autoria/responsabilidade editorial. Não atribuir o texto a um jornalista sem sua concordância.
- Acrescentar exemplos e perspectiva próprios quando houver; não inventar sessões assistidas, entrevistas ou experiência pessoal.
- Se houver imagem, registrar origem, licença/autorização e crédito. A pesquisa de fontes não autoriza copiar fotografias, capturas ou cartazes.
- Definir título, resumo, editoria e data real de publicação. Não retroagir datas.
- Publicar pelo fluxo editorial e verificar a URL e a atribuição. Um guia original não deve ser cadastrado como cópia de outra fonte.
- Não marcar o site como elegível só por haver três textos novos. O valor para o leitor e a análise do conjunto continuam pendentes.

Não há publicação automática destes rascunhos nem vínculo entre sua aprovação editorial e a aprovação do AdSense.
